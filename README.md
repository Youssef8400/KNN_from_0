##  Classification avec K-Nearest Neighbors (KNN)

Ce script implémente un **KNN from scratch** en Python pour classer des données depuis un fichier CSV.

### Fonctionnalités :
- Calcul de la distance euclidienne
- Recherche des K plus proches voisins
- Classification par vote majoritaire
- Prédiction sur un jeu de test
- Évaluation avec précision et matrice de confusion

### Utilisation :
1. Charger un fichier CSV contenant les données.
2. Choisir la valeur de `K` lors de l’exécution.
3. Obtenir la précision et la matrice de confusion.
